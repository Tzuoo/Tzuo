# 網頁專案規則

## 修改原則

- 本檔位於 Git 根目錄下的 `網頁/AGENTS.md`；在儲存庫根目錄執行 Git，勿再建立根目錄規則或說明副本。
- 公開儲存庫只發布 `網頁` 與 `油猴腳本` 兩類資料；根目錄 `Tzuo.html` 僅保留舊網址轉址，禁止當成完整頁面編輯。
- `油猴腳本` 成品來源是相鄰私人專案的 `腳本成品`，不可在公開副本直接修改或上傳帳密、權杖與本機設定。
- 修改前完整閱讀 `Tzuo.html` 的 HTML、CSS 與 JavaScript 呼叫關係。
- 保留既有頁面功能、資料格式與操作方式，只修改本次需求範圍。
- 完成後檢查 HTML 內嵌 JavaScript 語法、瀏覽器主流程與 `git diff --check`。
- 未在實際瀏覽器完成互動驗證的項目標示「待實測」。
- 完成修改後更新本檔調整紀錄，同一問題不重複新增。
