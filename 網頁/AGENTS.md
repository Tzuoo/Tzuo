# 網頁專案規則

## 修改原則

- 本檔位於 Git 根目錄下的 `網頁/AGENTS.md`；在儲存庫根目錄執行 Git，勿再建立根目錄規則或說明副本。
- 公開儲存庫只發布 `網頁` 與 `油猴腳本` 兩類資料；根目錄 `Tzuo.html` 僅保留舊網址轉址，禁止當成完整頁面編輯。
- `油猴腳本` 成品來源是相鄰私人專案的 `腳本成品`，不可在公開副本直接修改或上傳帳密、權杖與本機設定。
- 修改前完整閱讀 `Tzuo.html` 的 HTML、CSS 與 JavaScript 呼叫關係。
- 保留既有頁面功能、資料格式與操作方式，只修改本次需求範圍。
- 完成後檢查 HTML 內嵌 JavaScript 語法、瀏覽器主流程與 `git diff --check`。
- 未在實際瀏覽器完成互動驗證的項目標示「待實測」。
- 完成修改後更新本檔調整紀錄，同一問題不重複新增。

## 調整紀錄

### 2026-09-15：手機組數輸入

- 影響檔案：`網頁/Tzuo.html`、本檔；外層舊網址轉址頁不變。
- 原因：組數區原為 `div`，只接收實體鍵盤事件，手機無法喚起輸入法。
- 在原顯示區加入可聚焦的 numeric 文字輸入欄位，以 input／composition 事件接收手機與全形數字；保留實體鍵盤快捷鍵，避免重複輸入。
- 輸入過程保留聚焦欄位的 DOM，不可每打一碼重建欄位；新增確認／下一欄及加入清單觸控按鈕。
- 驗證：內嵌 JavaScript 語法及 `git diff --check` 通過；headless Edge 的 390px 手機型態回歸通過（連碰、小數價格、加入清單、單／雙位立柱、退格、車上限、實體鍵數字與 Enter），無頁面錯誤。真實手機輸入法喚起、連續輸入及外接鍵盤硬體仍待實測。
- 遠端已確認為 `Tzuoo/Tzuo`；推送會更新 GitHub Pages，發布前須取得使用者明確同意。

- 禁漫天堂 5.3.0 加入逐本移除收藏確認、帳號核對、失敗保留及快取同步；模擬回歸通過，真實網站操作待實測。

- `油猴腳本` 僅放四支成品，私人專案維護工具自動同步發布；自動簽到及參考腳本不公開。
